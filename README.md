# Shop API

Асинхронное API для интернет-магазина, созданное на FastAPI, с возможностью подключения разных БД. 

Бизнес-логика вынесена в отдельные классы (сервисы) а работа с данными в соответствующие классы (репозитории).

Проект содержит абстрактные интерфейсы репозиториев, что позволяет создать реализацию для конкретной БД. У меня созданы репозитории для работы с PostgreSQL.


## Реализованный функционал
- Регистрация и авторизация пользователей
- JWT-авторизация: access и refresh токены с ротацией, хранение refresh-токенов и сессий в базе данных
- Изменение пароля (юзером самостоятельно или админом)
- Валидация данных с Pydantic 2
- Кастомные исключения
- Логгирование
- Pydantic settings для конфигурации и работы с переменными окружения
- Миграции с alembic
- FastApi dependencies для управления доступом (admin/user), подключения сервисов (AuthService, UserService и т.д.) и выбора нужных репозиториев
- Основные эндпоинты для базовых сущностей (Product, Category, Order)


## Стэк
- Python 3.12+
- FastAPI
- Pydantic 2
- SQLAlchemy 2
- Postgres 17
- Alembic
