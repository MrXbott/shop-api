# Shop API

Асинхронный API для магазина, разработанный с использованием FastAPI, Pydantic и MongoDB. Проект реализует основные функции e-commerce backend-сервиса, включая управление пользователями, товарами и заказами. Предусмотрена авторизация и разграничение прав доступа.

## Технологии
- FastAPI
- Pydantic
- MongoDB
- Python 3.12
